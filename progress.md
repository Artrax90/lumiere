# Прогресс разработки и статус проекта Lumière

**Дата последнего обновления:** 23 сентября 2026 г.  
**Текущая версия:** 1.0.0 (Tizen Smart TV + Android APK + Web/Desktop)

---

## 📌 Архитектура и конфигурация окружения

- **Сервер (Backend):** Node.js / Fastify / TypeScript (`back/`)
  - Порт: `3000` (LAN: `http://192.168.1.77:3000`)
  - Локальная база: `back/data/local_db.json` (активна в отсутствие Postgres)
  - Публичная раздача APK: `http://192.168.1.77:3000/Lumiere-debug.apk`
- **Клиент (Frontend):** React / TypeScript / Vite / Tailwind CSS (`front/`)
  - Сборка раздаётся бэкендом из `back/public/`
- **Samsung Smart TV (Tizen 5.5 / TU8500):**
  - IP телевизора: `192.168.1.99:26101`
  - Пакет приложения: `6DD6uEqKQe.Lumiere` / `Lumiere.wgt` (370 КБ)
  - Установщик: `Install-On-TV.bat` на Рабочем столе (автоматическая установка + запуск на экране ТВ)
- **Мобильное приложение (Android):**
  - Пакет: `Lumiere-debug.apk` (подписан v1 + v2 + v3, 4-byte zipalign)
  - Расположение: Рабочий стол, папка «Загрузки», сервер Fastify

## 📋 Статус решения ключевых задач

### 1. Samsung Smart TV (Tizen)
- [x] **Обновление иконки приложения:** Подготовлена новая золотая иконка (`icon.png` и `shared/res/icon.png`).
- [x] **Очистка кэша старой иконки:** Пакет со старой иконкой деинсталлирован с ТВ для сброса кэша ОС.
- [x] **Автоматический запуск после установки:** В `Install-On-TV.bat` добавлен шаг автоматического открытия приложения через SDB и REST API сразу после завершения копирования.
- [x] **Инструкция по закреплению на главном экране:** Добавлены подсказки в консоль батника (APPS -> Настройки -> «Добавить на главный экран»).

### 2. Мониторинг, история просмотров и сессии
- [x] **Устранение спама в истории просмотров:** 
  - В `back/src/routes/sessions.ts` и `back/src/db/pool.ts` heartbeat теперь обновляет существующую запись за последние 4 часа (`watched_seconds = GREATEST(...)`, `ended_at = NOW()`), вместо создания сотен дубликатов каждые 5 секунд.
  - База `local_db.json` очищена от 100+ дубликатов.
- [x] **Отображение Live / IPTV в активных сессиях («Кто что смотрит сейчас»):**
  - В `front/src/api/server.ts` метод `serverFetch` автоматически добавляет `Content-Type: application/json` для запросов с телом.
  - В `Player.tsx` тип `live` нормализован в `iptv` для корректного отображения в интерфейсе активных сессий.
  - В `TvPlayer.tsx` добавлена отправка heartbeats и завершения сессии.

### 3. Синхронизация между устройствами и IPTV
- [x] **Разблокировка первой синхронизации:** В `front/src/api/sync.ts` снята блокировка, запрещавшая выгрузку плейлистов и избранного при пустой истории просмотров.
- [x] **Дефолтный IPTV-плейлист:** В `local_db.json` для всех пользователей прописан стартовый плейлист «Основной» (`https://loganettv.github.io/playlists/all.m3u`). При входе на любом устройстве каналы загружаются автоматически.

### 4. Мобильный клиент (Android APK)
- [x] **Автоскрытие меню (OSD) в видеоплеере:**
  - В `front/src/components/Player.tsx` добавлены обработчики касания `onTouchStart` и `onTouchMove`.
  - Тап по экрану плавно скрывает OSD.
  - Таймер автоскрытия на 3.5 секунды теперь срабатывает даже при видео на паузе.
- [x] **Адаптивная верхняя панель (TopNav):**
  - На мобильных экранах (`< 768px`) скрыты лишние кнопки (поиск, плагины, загрузки, настройки).
  - Счётчик уведомлений колокольчика выровнен и не наползает на соседние элементы.
  - Логотип слева и аватар с колокольчиком справа гармонично распределены по краям экрана.
- [x] **Сборка и подпись APK:** Скрипт `scratch/repack_apk.js` собирает APK без стриминговых дескрипторов (без крашей на ART), `uber-apk-signer` накладывает v1+v2+v3 подписи.

## 🛠️ Рабочие команды и скрипты быстрого доступа

| Действие | Команда / Скрипт |
| :--- | :--- |
| **Установка на ТВ** | Запустить `Install-On-TV.bat` на Рабочем столе |
| **Сборка WGT (ТВ)** | `node scratch/build_wgt.js` |
| **Сборка и подпись APK** | `node scratch/repack_apk.js` + подпись `uber-apk-signer` |
| **Сборка фронтенда** | `cd front && npm run build && Copy-Item -Recurse front/dist/* back/public/` |
| **Перезапуск бэкенда** | `cd back && npm run build` (сервер перезапускается) |
| **Прямая ссылка на APK** | `http://192.168.1.77:3000/Lumiere-debug.apk` |
