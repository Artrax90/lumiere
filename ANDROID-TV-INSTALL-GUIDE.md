# Руководство по установке Lumière на Android TV, Google TV и мобильные устройства

Lumière скомпилирован в единый универсальный APK-пакет, который поддерживает:
- **Android TV и Google TV** (Xiaomi Mi Box / TV Stick, Sony, Philips, TCL, Яндекс ТВ, SberBox);
- **Amazon Fire TV** (FireStick 4K / Cube);
- **Android-смартфоны и планшеты**.

Пакет включает официальную поддержку **Android TV Leanback Launcher** (отображается на главном экране ТВ-приложений с поддержкой пульта и D-pad навигации).

---

## 1. Расположение файла APK

Готовый установочный файл находится в корне репозитория:
```text
C:\antigravity\project\lumiere\Lumiere-debug.apk
```
*(Также доступен по ссылке с локального сервера: `http://192.168.1.77:3000/Lumiere-debug.apk`)*

---

## 2. Способ установки 1: Через приложение «Downloader» на Android TV (Самый простой)

1. Откройте **Google Play Store** на вашем телевизоре или ТВ-приставке.
2. Найдите и установите бесплатное приложение **Downloader by AFTVnews**.
3. Запустите Downloader и введите прямую ссылку на скачивание APK с вашего сервера:
   ```text
   http://192.168.1.77:3000/Lumiere-debug.apk
   ```
4. Нажмите **Go** → файл скачается, и откроется стандартный мастер установки Android. Нажмите **Установить**.

---

## 3. Способ установки 2: Через USB-флешку

1. Скопируйте файл `Lumiere-debug.apk` на обычную USB-флешку (FAT32 или NTFS).
2. Вставьте флешку в USB-порт телевизора или приставки.
3. Откройте любой файловый менеджер на ТВ (например, **X-plore File Manager** или **File Commander**).
4. Выберите `Lumiere-debug.apk` и подтвердите установку.

---

## 4. Способ установки 3: По сети через ADB (Беспроводная установка)

Если на телевизоре включена «Отладка по USB / по сети» (Раздел *Настройки → Для разработчиков → Отладка по сети*):

```bash
# 1. Подключение к телевизору по IP-адресу (например 192.168.1.80):
adb connect 192.168.1.80:5555

# 2. Установка приложения:
adb install -r C:\antigravity\project\lumiere\Lumiere-debug.apk
```

---

## 5. Первоначальная настройка после запуска на ТВ

1. При первом запуске приложение обнаружит сервер Lumière в локальной сети:
   - Если сервер запущен на этом ПК, адрес сервера: `http://192.168.1.77:3000`.
2. На экране появится выбор профилей («Кто смотрит?»):
   - Выберите свой профиль (Админ, Мама, Дети).
   - Если на профиле установлен 4-значный PIN-код, введите его с пульта.
3. Приложение полностью готово к просмотру фильмов, сериалов, торрентов и IPTV!
