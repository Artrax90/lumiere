## 🌟 Почему именно Lumière?

Большинство домашних медиацентров требуют либо предварительного скачивания гигабайт файлов на жесткий диск, либо сложной настройки десятка разрозненных плагинов. **Lumière** объединяет лучшие технологии современного стриминга в едином, красивом и готовом к использованию решении «всё в одном»:

* ⚡ **Смотрите торренты сразу**: воспроизведение видео начинается через 2–4 секунды прямо из раздачи без засорения диска.
* 🍿 **Интерфейс уровня флагманских онлайн-кинотеатров**: плавные анимации, кинематографичные баннеры, трейлеры, умные подборки и топ-10.
* 📺 **Настоящий Smart TV опыт**: приложения разработаны специально под физические пульты (D-Pad навигация, фокус, горячие клавиши).
* 🔒 **Полная приватность и автономность (Self-Hosted)**: сервер работает на вашем оборудовании, данные истории просмотров и профилей принадлежат только вам.

## ✨ Основные возможности

### 🎬 Богатый каталог и умные рекомендации
* **Интеграция с TMDB**: постеры сверхвысокого разрешения, синопсисы, актерский состав, возрастные рейтинги и видео-трейлеры прямо в карточке фильма.
* **Netflix Топ-10**: динамический топ популярных картин с удобным переключателем периода (*За день / За неделю / За всё время*).
* **Персонализированная полка «Рекомендации для вас»**: анализ истории просмотров профиля и подбор похожего контента.
* **Франшизы и Киновселенные**: коллекции Marvel, DC, «Гарри Поттер», «Звёздные войны», «Властелин колец» в хронологическом порядке.
* **Каталог Аниме**: сериалы, OVA и полнометражные ленты со сводками и удобной навигацией по эпизодам.
* **Умный плеер сериалов**: автоматическая группировка по сезонам, превью серий, отметки просмотренного и кнопка «Следующая серия».

### ⚡ Торрент-стриминг нового поколения
* **Встроенный движок TorrServer MatriX**: буферизация в оперативную память без износа SSD/HDD.
* **Агрегатор релизов JacRed**: мгновенный парсинг доступных раздач прямо из окна фильма/сериала.
* **Умные фильтры качества**: сортировка по разрешению (4K HDR, 1080p, 720p), сидам, размеру файла, озвучкам и студиям дубляжа.
* **Автоматический выбор лучшей раздачи**: кнопка мгновенного запуска самого популярного релиза в один клик.

### 🔄 Универсальный видеоплеер (Direct Play + FFmpeg HLS)
* **Воспроизведение без лагов**: автоматический Direct Stream при поддержке кодека устройством, либо транскодирование на лету через **FFmpeg** для неподдерживаемых браузером контейнеров (MKV, AVI, 10-bit HEVC, DTS, AC3).
* **Аудиодорожки и субтитры**: мгновенное переключение дубляжа и дорожек, встроенные и внешние субтитры.
* **Синхронизация прогресса**: точное возобновление просмотра с секунды остановки на любом другом устройстве.

### 📡 IPTV и Онлайн-телевидение
* **Поддержка плейлистов M3U / M3U8**: загрузка через URL или файл.
* **Интерактивная телепрограмма (EPG)**: текущая передача, шкала эфирного прогресса и анонс следующих передач.
* **Удобная сортировка**: группировка по категориям (Спорт, Кино, Новости, Познавательное, Детское) и раздел «Избранные каналы».

### 👨‍👩‍👧‍👦 Профили и Семейный доступ
* **Экран выбора «Кто смотрит?»**: независимые закладки, избранное и прогресс для каждого члена семьи.
* **Детский режим (Kids Mode)**: скрытие контента 18+ и взрослой библиотеки для детских профилей.
* **Защита PIN-кодом**: 4-значный код безопасности для защиты профилей взрослых.

### ⚙️ Лаконичный центр управления
* **6 чистых рабочих вкладок**:
  1. *Общие* — язык интерфейса, тема оформления, настройки автовоспроизведения.
  2. *Каталог (TMDB)* — API-ключ, выбор зеркал и настройка SOCKS5/HTTP прокси при ограничениях провайдера.
  3. *Торренты* — подключение к TorrServer, JacRed, настройки буфера памяти.
  4. *IPTV* — управление плейлистами M3U и XMLTV телепрограммой.
  5. *Профили* — создание, редактирование аватаров, смена PIN-кодов.
  6. *О системе* — проверка обновлений, информация о сервере, быстрые ссылки на скачивание APK и WGT.

## 🚀 Быстрый старт: Docker Compose

Самый простой, стабильный и изолированный способ запуска всей инфраструктуры (Lumière + PostgreSQL + TorrServer).

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Artrax90/lumiere.git
cd lumiere
```

### 2. Подготовьте файл переменных окружения
```bash
cp .env.example .env
```
*(При необходимости отредактируйте `.env` — укажите ваш TMDB_TOKEN и желаемые порты).*

### 3. Запустите контейнеры
```bash
docker compose up -d
```

### 4. Откройте в браузере
Перейдите по адресу:  
👉 **[http://localhost:3500](http://localhost:3500)** *(или `http://<IP_ВАШЕГО_СЕРВЕРА>:3500` в локальной сети)*.

При первом входе система предложит создать аккаунт первого администратора, после чего вы сразу перейдете в кинотеатр.

## ⚙️ Конфигурация (.env)

Основные параметры конфигурации сервера:

| Параметр | По умолчанию | Назначение |
| :--- | :--- | :--- |
| `PORT` | `3500` | Порт веб-приложения и REST API |
| `TORRSERVER_PORT` | `8590` | Внешний порт TorrServer для прямого стриминга |
| `TMDB_TOKEN` | *опционально* | API Read Access Token от TMDB ([Получить бесплатно](https://www.themoviedb.org/settings/api)) |
| `TMDB_PROXY_URL` | *опционально* | SOCKS5 или HTTP прокси (например, `socks5://user:pass@host:1080`), если TMDB заблокирован |
| `DB_HOST` | `postgres` | Имя хоста базы данных PostgreSQL в Docker-сети |
| `DB_PORT` | `5432` | Порт базы данных PostgreSQL |
| `DB_USER` | `lumiere` | Имя пользователя базы данных |
| `DB_PASS` | `lumiere123` | Пароль базы данных |
| `DB_NAME` | `lumiere` | Имя базы данных |
| `TORRSERVER_URL` | `http://torrserver:8590` | Внутренний URL TorrServer для связи бэкенда со стримером |
| `JACRED_URL` | `http://ns3bg91xvuqfvq9h.cfhttp.top` | Зеркало или локальный адрес сервиса поиска раздач JacRed |
| `JWT_SECRET` | *секретный_ключ* | Секретная строка для подписи токенов авторизации |
| `INVITE_REGISTRATION` | `true` | Регистрация новых пользователей строго по приглашениям |
| `ADMIN_SECRET` | *секретный_ключ* | Секретный код для генерации приглашений администратора |

> [!NOTE]
> Токен TMDB и прокси-сервер можно изменить прямо в работающем интерфейсе во вкладке **Настройки → Каталог (TMDB)** без перезапуска сервера!

## 🛠️ Локальная разработка и ручной запуск (без Docker)

Если вы хотите вносить изменения в исходный код или разрабатывать новые фичи:

### Системные требования:
* **Node.js**: v20.0.0 или новее
* **PostgreSQL**: v14+
* **FFmpeg** и **FFprobe**: установлены в системе и доступны в `PATH`
* **TorrServer MatriX**: запущен локально на порту `8590`

### Пошаговая сборка:

```bash
# 1. Установка зависимостей
cd back && npm install
cd ../front && npm install
cd ..

# 2. Настройка базы данных
cp .env.example back/.env
# Задайте актуальные параметры подключения к вашей локальной базе PostgreSQL в back/.env

# 3. Сборка фронтенда
cd front && npm run build
cd ..

# 4. Запуск бэкенда в режиме разработки
cd back
npm run dev
```

Для пользователей Windows подготовлен скрипт запуска в один клик:
```cmd
start.bat
```

## 📱 Сборка клиентских приложений

В репозитории реализованы скрипты для сборки всех типов клиентов:

### 1. Samsung Tizen TV (`Lumiere.wgt`)
Требуется установленный **Tizen Studio CLI**:
```cmd
tizen.bat package -t wgt -s LumiereSamsungProfile -- front/tizen
```
Пакет будет сгенерирован и автоматически готов к отправке на ТВ через SDB: `sdb install Lumiere.wgt`.

### 2. Android TV Native APK (`Lumiere-tv.apk`)
Сборка специализированной версии для телевизоров с нативной D-Pad навигацией:
```bash
node scratch/build_native_tv.cjs
# Либо через Gradle:
cd android && ./gradlew :tv:assembleDebug
```

### 3. Android Mobile APK (`Lumiere.apk`)
Сборка сенсорной мобильной версии через Capacitor & Gradle:
```bash
cd android && ./gradlew :mobile:assembleDebug
```

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Фильмы не загружаются или выдается ошибка сети при поиске постеров</b></summary>
<br/>
Сервис TMDB может быть заблокирован интернет-провайдером в вашем регионе.  
Решение: откройте в приложении <b>Настройки → Каталог (TMDB)</b> и укажите адрес SOCKS5/HTTP прокси, либо впишите параметр <code>TMDB_PROXY_URL</code> в файле <code>.env</code>.
</details>

<details>
<summary><b>2. Долго ли буферизуется видео при запуске торрента?</b></summary>
<br/>
При стабильном интернет-подключении и наличии раздающих (сидов) предбуферизация занимает от 2 до 5 секунд. Вы также можете настроить размер буфера предварительного чтения в <b>Настройках → Торренты</b>.
</details>

<details>
<summary><b>3. Как управлять воспроизведением на Smart TV с пульта?</b></summary>
<br/>
Интерфейс оптимизирован для управления стрелками (Вверх/Вниз/Влево/Вправо), кнопкой выбора (OK/Enter) и кнопкой возврата (Back). Во время воспроизведения стрелки вверх/вниз вызывают оверлей с выбором аудиодорожек, субтитров и серий, а влево/вправо осуществляют точную перемотку.
</details>

<details>
<summary><b>4. Поддерживается ли звук 5.1 и многоканальный AC3/EAC3/DTS?</b></summary>
<br/>
Да. Если целевое устройство или ТВ аппаратно поддерживает многоканальный звук, плеер передает поток напрямую (Direct Stream). Если браузер клиента не поддерживает аудиокодек, серверный модуль FFmpeg автоматически преобразует его на лету в стерео AAC или совместимый HLS поток.
</details>
