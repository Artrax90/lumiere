## 🥊 В чем разница? Lumière vs Остальные

Зачем скачивать гигабайты на жесткий диск и ждать часами, если можно нажать **Play** и смотреть прямо сейчас?

| Что важно при просмотре? | Обычные торренты | Plex / Jellyfin | 🎬 **Lumière** |
| :--- | :---: | :---: | :---: |
| **Время до старта фильма** | ⏱️ 15–60 минут скачивания | ⏱️ Нужно заранее загрузить в библиотеку | ⚡ **2–4 секунды** (потоковый старт) |
| **Место на диске** | 💾 Нужны терабайты SSD/HDD | 💾 Огромные хранилища файлов | 🟢 **0 байт** (буферизация прямо в RAM) |
| **Опыт на Smart TV** | ❌ Неудобно, мышка/костыли | ⚠️ Требуются плагины и тонкая настройка | 📺 **Родной пульт D-Pad, звук 5.1 и 4K HDR** |
| **Поиск раздач и озвучек** | 🔍 Ручной серфинг по трекерам | ❌ Только то, что сам добыл и положил в папки | 🚀 **Автопоиск 50+ релизов с фильтрами по студиям** |
| **Кино, сериалы, аниме и ТВ** | ❌ Разрозненный зоопарк софта | ❌ Нет нативной интеграции с торрент-потоками | 🍿 **Всё в одном приложении из коробки** |
| **Стоимость и приватность** | Реклама и трояны на трекерах | Платные Plex Pass / сторонние сервисы | 🛡️ **100% Free & Open-Source (Self-Hosted)** |

## ⚡ Быстрый старт за 60 секунд

Всё упаковано в единый Docker-стек (PostgreSQL 16 + движок TorrServer + Fastify Backend + React Web UI):

```bash
# 1. Клонируй репозиторий
git clone https://github.com/Artrax90/lumiere.git && cd lumiere

# 2. Подними весь стек одной командой
docker compose up -d
```

👉 Открой в браузере: **[http://localhost:3500](http://localhost:3500)** *(или IP твоего сервера в домашней сети)*.  
Создай профиль админа при первом входе — и домашний кинотеатр готов к просмотру!

## 🔥 Фичи, которые влюбляют в себя

### 🎬 Атмосфера настоящего премиального стриминга
* **Живые промо-баннеры и трейлеры**: видео-превью запускаются прямо на фоне при наведении фокуса.
* **Netflix Топ-10**: актуальный рейтинг самых горячих новинок с мгновенным переключением периода (*За день*, *За неделю*, *За всё время*).
* **«Рекомендации для тебя»**: умная лента, которая анализирует твои просмотры и предлагает ленты под твой персональный вкус.
* **Франшизы и Вселенные**: смотри хронологию Marvel, Звездных войн, Гарри Поттера или Властелина колец без путаницы в частях.
* **Каталог Аниме**: огромная коллекция онгоингов и классики с удобной группировкой эпизодов и озвучек.

### ⚡ Торрент-стриминг нового поколения
* **Никакого износа дисков**: поток принимается движком TorrServer MatriX и кэшируется в оперативной памяти (RAM).
* **Молниеносный парсер JacRed**: за доли секунды собирает десятки раздач со всех популярных трекеров.
* **Умные бейджи качества**: 4K UHD, HDR10, Dolby Vision, 1080p, студии перевода (Дубляж, Red Head Sound, LostFilm, Кубик в Кубе).
* **Автостарт в 1 клик**: жми кнопку «Смотреть» — плеер сам подберет стабильную раздачу с максимальным числом сидов.

### 🍿 Всеядный видеоплеер
* **FFmpeg On-The-Fly Transcoding**: если ТВ или браузер не поддерживает звук DTS, AC3, аудиодорожки 5.1 или кодек HEVC 10-bit, сервер на лету переупаковывает поток в совместимый HLS без потери качества.
* **Выбор дорожек и субтитров**: переключай озвучку прямо во время воспроизведения в удобном оверлее.
* **Синхронизация прогресса на лету**: начни смотреть фильм в гостиной на телевизоре, а досматривай в постели со смартфона ровно с той же секунды.

### 📡 IPTV и Онлайн-телевидение
* **Твои любимые каналы**: простая загрузка любых M3U / M3U8 плейлистов по ссылке или файлом.
* **Интерактивная телепрограмма (EPG)**: удобная сетка эфира, шкала текущего времени и описание передач.
* **Категории и Избранное**: спорт, новости, детское, киноканалы — всё структурировано.

### 👨‍👩‍👧‍👦 Профили для всей семьи
* **Экран «Кто сейчас смотрит?»**: персональная история, закладки и рекомендации для каждого.
* **Детский режим (Kids Mode)**: фильтрация контента 18+ для детских глаз.
* **Защита PIN-кодом**: защити родительский профиль 4-значным пином.

## ⚙️ Тонкая настройка (.env)

Файл `.env` создается из шаблона `.env.example`:

```ini
PORT=3500                             # Порт веб-приложения и API
TORRSERVER_PORT=8590                  # Порт стримера TorrServer
TMDB_TOKEN=                           # Бесплатный API токен от themoviedb.org
TMDB_PROXY_URL=                       # Прокси (socks5://... или http://...), если TMDB заблокирован
TORRSERVER_URL=http://torrserver:8590 # Внутренняя связь бэкенда со стримером
JACRED_URL=http://ns3bg91xvuqfvq9h.cfhttp.top # Зеркало парсера раздач
DB_USER=lumiere                       # Пользователь БД
DB_PASS=lumiere123                    # Пароль к БД
DB_NAME=lumiere                       # Название БД
```

> [!NOTE]
> Менять токен TMDB и прокси можно прямо из интерфейса во вкладке **Настройки → Каталог (TMDB)**, ничего не перезапуская!

## 💬 FAQ

<details>
<summary><b>🔥 Почему не грузятся постеры фильмов?</b></summary>
<br/>
TMDB (The Movie Database) часто блокируется провайдерами в РФ. Зайди в <b>Настройки → Каталог (TMDB)</b> в приложении и укажи адрес любого рабочего HTTP или SOCKS5 прокси. Постеры и описания появятся мгновенно.
</details>

<details>
<summary><b>⚡ Сколько оперативной памяти нужно для TorrServer?</b></summary>
<br/>
Для комфортного просмотра 4K HDR рипов достаточно выделить 200–500 МБ кэша в оперативной памяти. Износ диска при этом равен нулю.
</details>

<details>
<summary><b>📺 Работает ли пульт на Android TV и ТВ-боксах (Mi Box, Ugoos, Shield)?</b></summary>
<br/>
Да! В нативном приложении <code>Lumiere-tv.apk</code> встроена полноценная D-Pad навигация: стрелки перемещают фокус, OK открывает фильм, Back возвращает назад, а кнопки вверх/вниз в плеере вызывают меню выбора дорожек и серий.
</details>
