# Руководство по установке Lumière на Samsung Smart TV (Tizen)

Данное руководство описывает **способы запуска и установки Lumière** на телевизорах Samsung Smart TV (Tizen OS).

---

## Способ 1: Экспресс-запуск через MediaStationX (MSX) — Без Developer Mode и сертификатов (Рекомендуется)

**Media Station X (MSX)** — официальное бесплатное приложение из магазина Samsung Smart Hub. Этот способ позволяет запустить полную версию Lumière за 1 минуту без компьютера, без командной строки и без создания сертификатов разработчика!

### Пошаговая инструкция:
1. **Установите Media Station X** на телевизоре:
   - Откройте **Smart Hub** (кнопка Домой на пульте) → перейдите в **Apps (Приложения)**.
   - В поиске введите `Media Station X` и нажмите **Установить**.
2. **Настройте адрес запуска Lumière**:
   - Запустите приложение **Media Station X**.
   - Перейдите в **Settings** (Настройки) → **Start Parameter** (Стартовый параметр) → **Setup** (Настроить).
   - Введите адрес вашего сервера Lumière:
     ```text
     <YOUR_SERVER_IP>:3000/msx
     ```
     *(Например: `192.168.X.X:3000/msx`)*.
   - Нажмите галочку / **Enter** для сохранения.
3. **Запустите Lumière**:
   - Media Station X сразу же загрузит интерфейс Lumière TV на весь экран с аппаратной поддержкой видеоплеера, пульта и IPTV!

## Способ 2: Установка нативного пакета (.wgt) через Developer Mode и SDB

Этот способ устанавливает Lumière как самостоятельное отдельное приложение в меню Samsung Smart Hub.

### Шаг 1. Включение Developer Mode на телевизоре
1. Нажмите кнопку **Home** на пульте телевизора и откройте раздел **Apps**.
2. На стандартном цифровом пульте телевизора наберите последовательно комбинацию:
   ```text
   1 2 3 4 5
   ```
   *(Если у вас смарт-пульт без цифр, откройте экранную цифровую клавиатуру на ТВ и введите 1-2-3-4-5)*.
3. Появится синее окно **Developer Mode Configuration**:
   - Переведите тумблер **Developer Mode** в положение **ON**.
   - В поле **Host PC IP** введите IP-адрес вашего компьютера.
   - Нажмите **OK**.
4. **Перезагрузите телевизор**:
   - Зажмите кнопку питания на пульте на 3–5 секунд, пока на экране не появится заставка Samsung, либо выключите телевизор из розетки на 10 секунд.

### Шаг 2. Установка через SDB (командная строка)
Если вы используете Tizen Studio или утилиту `sdb`:
```bash
# 1. Подключение к телевизору по IP (порт 26101):
sdb connect <TV_IP>:26101

# 2. Проверка подключения:
sdb devices

# 3. Установка пакета:
tizen install -s <TV_IP> --name Lumiere.wgt -- .
```

## Способ 3: Через встроенный браузер телевизора

Телевизор может подключаться к локальному серверу Lumière прямо через встроенный браузер Samsung Internet:
- Откройте браузер на ТВ и перейдите по адресу:
  ```text
  http://<YOUR_SERVER_IP>:3000/tv/
  ```
- Нажмите «Добавить в закладки» или «Закрепить на главном экране Smart Hub».
- Интерфейс автоматически оптимизируется под разрешение 4K/Full HD и пульт дистанционного управления.
